# Intent Qualification
A system 
for qualifying and ranking companies based on natural-language user queries. 

Developed for the Veridion ML Engineer Intern Intent Qualification challenge.

## Project Structure

- `solution.py` = entry point for the system
- `src/` = supporting implementation modules
- `WRITEUP.md` = approach, design decisions, evaluation and analysis
- `requirements.txt` = python dependencies
- `data/` = local dataset directory (dataset not included in the repository)
